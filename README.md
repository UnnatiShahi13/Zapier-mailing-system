# Zapier AI Agent – Automated Payment Reminder & Reconciliation

## Project Overview

This project demonstrates an AI-powered Zapier Agent developed to automate invoice payment reminders and payment reconciliation using Gmail and Google Sheets.

## Workflow

The agent performs the following steps:

1. Retrieves invoice records from Google Sheets.
2. Identifies invoices with pending payment status.
3. Determines the appropriate recipient based on invoice type.
4. Sends personalized payment reminder emails through Gmail.
5. Processes payment confirmation replies.
6. Extracts transaction IDs from customer emails.
7. Matches the transaction ID with the relevant invoice.
8. Updates the payment status and transaction ID in Google Sheets.
